一、软件简介

Lens Drawing 是一款专为光学镜片加工设计的桌面应用程序，用于自动生成符合规范的镜片工程图 PDF 文件。软件当前版本为 V3.1。

主要功能

自定义出图

手动输入单片/双胶合/三胶合参数，实时预览并导出 PDF

批量处理

Excel/CSV 批量导入，一键导出全部 PDF 工程图

参数设置

配置加工要求、公差、镀膜、绘图等全局默认参数

启动方式

双击桌面快捷方式 LensDrawing 或运行安装目录下的主程序即可启动。启动后显示主界面（启动页）。

二、主界面（启动页）

启动页提供三个功能入口按钮：

按钮功能说明
批量处理批量导入与导出适合需要同时处理多个镜片的生产场景
自定义出图单件镜片出图适合单独绘制一个镜片或胶合组件的工程图
参数设置全局默认配置设置加工要求、公差、镀膜等默认值，影响所有模块
提示点击左上角「返回」按钮可随时回到启动页。

三、自定义出图

自定义出图模块分为 左侧参数面板 和 右侧预览区域。修改左侧参数后，右侧预览图会自动更新。

3.1 镜片类型选择

在参数面板顶部选择镜片类型：

类型说明PDF 页数
单片单个独立镜片1 页
双胶合两片镜片胶合在一起3 页（组装图 + 2 个单片页）
三胶合三片镜片胶合在一起4 页（组装图 + 3 个单片页）

选择双胶合或三胶合后，参数面板会自动展开对应的第 2、第 3 片参数输入框。

3.6 CA 模式

  • 自动计算（推荐）：CA = 系数 × AD，向下取一位小数。系数可在「CA 系数」框中修改（默认 0.94）
  • 手动输入：选择手动模式后出现 CA1、CA2 输入框

3.7 倒角模式

  • 自动计算（推荐）：根据 MD 口径和曲率自动判断，详见第六章
  • 手动输入：选择手动模式后出现左侧/右侧倒角输入框（单位 mm）

3.8 公差设置

参数含义默认值
厚度公差中心厚度公差（±mm）0.02
矢高公差矢高公差（±mm）0.02
定位上偏差直径定位公差上偏差 (mm)0.010

注意胶合镜片还有一个「胶合定位镜片」选项（第 1/2/3 片），定位镜片采用定位公差，其余镜片采用非定位公差。

3.9 实时预览与覆盖层

  • 右侧预览区会实时显示当前参数生成的工程图
  • 点击预览区底部「显示输入框」按钮，可以在预览图上叠加显示可编辑的参数输入框
  • 输入框中的数值可以直接点击修改，修改后预览立即更新
  • 此功能方便快速微调个别参数，无需回到左侧面板

3.10 多页预览切换

双胶合和三胶合镜片会生成多页预览（组装图 + 各单片页），通过预览区底部的 页签标签 切换不同页面。

3.11 导出 PDF

  1. 点击右上角 导出按钮（向下箭头图标）
  2. 在弹出的对话框中输入文件名
  3. 点击「选择路径」选择保存目录
  4. 点击「导出」，系统将生成 PDF 文件
提示点击顶部栏「重置参数」按钮（环形箭头图标）可将所有参数恢复为默认值。

4.2 Excel/CSV 导入

  1. 切换到「Excel/CSV 导入」标签页
  2. 点击上传区域或拖拽文件到上传区域
  3. 支持格式：.xlsx、.xls、.csv
  4. 系统自动解析并显示导入预览表
  5. 确认无误后点击「导入到编辑器」，数据将合并到表格编辑器中
Excel 列名规范 第一行为列名标题，必须包含以下列（按镜片类型）：
  • 单片必需列：PartName, PartNo, Glass1, T1, R1, R2, MD1, AD1, AD2
  • 双胶合额外必需列：Glass2, T2, R3, MD2, AD3
  • 三胶合额外必需列：Glass3, T3, R4, MD3, AD4
  • 可选列：SavePdfFolder, MfrPdfFolder（自定义输出子文件夹名）

4.3 存档 PDF 与编码 PDF

批量导出时，系统自动在输出目录下创建两个子文件夹：

文件夹命名规则说明
存档 PDF默认 Save PDF，可自定义PDF 以 PartName 命名，表格显示 PartName
编码 PDF默认 Mfr PDF，可自定义PDF 以 PartNo 命名，表格隐藏 PartName

在工具栏中可以统一修改存档 PDF 和编码 PDF 的文件夹名称。

4.4 PartNo 料号与自动填充

  • 在工具栏「料号」输入框中填入基础料号（如 105.2.00599）
  • 添加新行时，PartNo 将自动递增填充
  • PartName 也会根据编码规则自动生成

4.5 逐行个性化出图参数

点击每行「加工」列的按钮，弹出加工参数编辑窗口，可为该行单独设置：

  • 加工要求（C、B、N、ΔN、署名、品级）
  • 倒角 & CA（倒角模式、CA 模式及对应参数）
  • 公差（厚度、矢高、定位/非定位偏差）
  • 镀膜参数（S1/S2 波段、反射率、角度）

未单独设置的行将使用「参数设置」中的全局默认值。

4.6 批量 PDF 导出

  1. 确认表格数据无误
  2. 点击右上角 批量导出按钮（向下箭头图标）
  3. 选择输出目录
  4. 系统将逐行生成 PDF，分别输出到存档 PDF 和编码 PDF 子文件夹
  5. 导出完成后显示成功/失败统计
提示导出时还会同步生成一份可重新导入的 Excel 表格，方便后续复用数据。

六、自动计算规则参考

6.1 倒角自动计算规则

基于口径的基本规则

机械口径 MD (mm)倒角值 (mm)
MD ≤ 300.2
30 < MD ≤ 800.3
MD > 800.4

双凸/双凹特殊规则

当镜片为 双凸（R1 > 0，R2 < 0）或 双凹（R1 < 0，R2 > 0）时：

若 ||R1| − |R2|| / min(|R1|, |R2|) ≤ 70%，则：

  • 左侧倒角 = 0.2 mm
  • 右侧倒角 = 0.4 mm

（忽略上述口径分级规则）

注意胶合镜片的单片页仅使用口径基本规则（不分左右），组装页同上。

6.2 N（光圈数）自动计算规则

机械口径 MD (mm)N 值
MD ≤ 151.5
15 < MD ≤ 302
30 < MD ≤ 803
80 < MD ≤ 1304
130 < MD ≤ 1806
MD > 1808

6.3 CA 自动计算公式

CA = floor(系数 × AD × 10) / 10

即：系数 × AD 的结果向下取一位有效小数。

示例AD系数计算过程CA 结果
1920.940.94 × 92 = 86.48 → floor(864.8)/1086.4
213.50.940.94 × 13.5 = 12.69 → floor(126.9)/1012.6
3500.950.95 × 50 = 47.5 → floor(475)/1047.5

七、常见问题与注意事项

预览图显示「验证错误」怎么办？

常见原因：

  • T（中心厚度）≤ 0
  • MD（机械口径）≤ 0
  • AD 大于 MD
  • |R| 的绝对值 ≤ AD/2（曲率半径太小，无法形成弧线）

请检查并修正对应参数值。

批量导出时部分行失败？

导出完成后会显示成功/失败统计和详细错误信息。常见原因包括：

  • 该行参数不完整（如双胶合缺少 Glass2 或 T2）
  • 参数验证不通过（同上一问题）
  • 输出路径无写入权限
参数修改后预览图没有更新？

预览图会在参数变化后自动刷新。如果未更新，请尝试：

  • 点击任意输入框使其失去焦点（触发更新）
  • 切换到其他页面再返回
如何导入之前导出的 Excel？

批量导出生成的 Excel 表格与导入格式兼容，可直接在「Excel/CSV 导入」标签页中重新导入。

胶合镜片工程图有几页？
类型页数内容
单片1 页单片工程图
双胶合3 页组装图 + 镜片 1 单页 + 镜片 2 单页
三胶合4 页组装图 + 镜片 1/2/3 各一页
设置保存在哪里？

所有设置保存在软件目录下的 app_settings.json 文件中。重装软件时备份该文件可保留自定义设置。

程序启动失败怎么办？

程序会在桌面生成错误日志文件 LensDrawing_error.log，请将日志内容反馈给技术支持。

重要警告请勿在程序运行时手动删除或修改 app_settings.json 文件，以免造成设置丢失或程序异常。
